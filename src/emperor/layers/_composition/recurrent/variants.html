What they share

Transition pipeline

Normalization and memory can act around the block. Postprocessing and the recurrent residual follow, with an optional final normalization. In Inner Thinking these controllers operate around the entire token update.

Gradient boundary and depth

The schedule counts block transitions for gradients and complete iterations for depth growth. If the first transitions run without gradients, the model detaches the carried state before the first tracked transition. Optional smooth growth blends adjacent depths.

Halting and return

The step updates the configured halting model only at an eligible transition. The loop stops at its limit or when all items have halted. Finalization can produce a weighted output and auxiliary loss before the caller’s layer state is updated.
