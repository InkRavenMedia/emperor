# Workbench fonts

The root layout loads these fonts locally so development and production builds do not depend on live Google Fonts responses.

The Plus Jakarta Sans and JetBrains Mono variable font files come from the Google Fonts repository at revision `5bb28733cec313b63fbd415b574b5ae35c8aa8b8`. They were converted from TTF to WOFF2 without subsetting. Each font’s SIL Open Font License is included beside it.
